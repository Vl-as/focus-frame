# 📸 Focus Frame

A modern and responsive landing page for an online photography course platform.

The project focuses on creating a clean user interface, responsive layouts, and a well-organized CSS structure based on a provided design.

---

## 🚀 Live Demo

🔗 https://vl-as.github.io/focus-frame/

---

## ✨ Features

- 📱 Fully responsive design
- 🎨 Modern educational platform landing page
- 🧩 Structured page sections
- 📐 Adaptive layout for different screen sizes
- 🖱 Interactive UI elements
- ♻️ Organized and reusable CSS styles
